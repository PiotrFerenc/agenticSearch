# Korekty zbiorcze z pliku CSV

Moduł: Sprzedaż > Faktury > Import korekt.
Plik CSV: separator `;`, kodowanie UTF-8, kolumny: NumerFaktury;Pozycja;NowaIlosc;NowaCena.
Maksymalnie 500 wierszy na import. Wymagane uprawnienie `Faktury.KorektaZbiorcza`.

Najczęstszy błąd: "Nieprawidłowy format pliku" – plik zapisany w Excelu jako ANSI zamiast UTF-8.
